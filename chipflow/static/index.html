    GETTING STARTED

    A clear path from code to layout

    01

    Test your RTL

    Choose “Simulate RTL.” Chipflow runs your testbench and looks for its success message. Download the waveform to inspect signals in a local viewer.

    02

    Build the gates

    Choose “Create a gate-level netlist.” Synthesis maps your RTL to cells in the selected technology library. Gate simulation can test this netlist with compatible cell models.

    03

    Create the layout

    Choose “Generate the final layout.” Chipflow runs synthesis, floorplanning, placement, the clock tree, routing, and finishing in order.

    04

    Review the results

    Completion means the requested tools finished. Timing and router checks are shown separately. Full physical signoff is not established by this application.

    Working with your own design

    Use Create project and enter paths to files on this computer. Files inside an existing YAML configuration resolve relative to that configuration. The project form uses the workspace folder for relative paths.

    If a run fails

    Its inputs and logs are saved. Open Live logs for the tool’s error, then fix your project and start a new run. “Run again” uses the saved inputs from the selected run.
    EXPERT CONFIGURATION

    Edit the complete project YAML

    All supported clocks, constraints, Tcl hooks, native variables, library files, and timeouts are editable here. Saving creates a new project copy.

    Existing paths are resolved for the new copy. New relative paths start in the workspace folder. Script contents are edited in your local Tcl files.

    Source configurations and previous runs are preserved.
